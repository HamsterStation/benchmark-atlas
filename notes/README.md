# 人工复现笔记

一篇论文对应一个 `<稳定 ID>.md`。此目录仅供人工维护，采集程序不读取或写入其中内容。
页面将 Markdown 作为数据解析，禁用原始 HTML 和危险链接；不会编译成 MDX。

没有执行实验就不要新建“已跑通”记录。真正运行后，使用下面的结构：

```markdown
# 复现记录

- 日期：
- 操作者：
- 官方仓库与完整 commit：
- 环境：操作系统、硬件、Python、依赖锁文件
- 官方命令来源：带 commit 的文档链接
- 验证范围：最小示例 / 具体实验、数据切分、样本数
- 执行命令：原始命令与有理由的本地修改
- 结果：输出、失败情况、日志路径
- 指定实验对比：论文指标、实测指标、误差及限制
```

随后在 curated JSON 的 `reproduction.runs` 中记录结构化信息，并把 `notePath` 设置为本 Markdown 的文件名。
本站开发和自动采集流程禁止执行论文仓库代码。人工复现应在维护者明确授权的隔离环境中另行开展。
