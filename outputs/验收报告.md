## 你需要设置什么

先审阅根目录中文 `README.md`，再自行创建/上传 GitHub 仓库。

1. Pages 的 Source 选择 **GitHub Actions**，确认 `github-pages` environment 允许默认分支部署。
2. Actions 允许官方工作流及创建 PR；允许机器人向 `atlas-state`、`atlas-review` 分支普通推送。现有分支保护不绕过，受保护主分支仍由人审核合并。
3. 首次手动运行采集时保持 **dry_run=true**。确认后设 Repository Variable **COLLECTION_ENABLED=true**，启用每天北京时间 10:20 的持久采集。
4. 决定发布后才设 **PAGES_ENABLED=true**，手动运行 Deploy reviewed site。默认 **PUBLISH_MODE=review**，auto 需显式选择。
5. 基础采集、审核 PR 和 Pages 不需要额外 PAT 或模型 Secret。若需要模型草稿，配置 Secret **MODEL_API_KEY**，以及 Variables **MODEL_API_URL**、**MODEL_NAME**。

仓库子路径由仓库名称自动计算；普通仓库使用 `/仓库名/`，`owner.github.io` 用户站使用 `/`。详细权限、手工添加、审核与失败队列恢复说明均在根目录 README。
